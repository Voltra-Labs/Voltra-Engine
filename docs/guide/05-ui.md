# 5. UI

## The HUD

An entity with a **`UiRect`** is drawn on the screen, not in the world: its
`Sprite` fills the rect, its `Text` is laid out inside it. Anchors are
fractions of the parent rect (or the screen), offsets are points added to
them — Godot's anchors and offsets. Scene ▸ Spawn HUD text / panel /
button / column / toggle / slider / text field / scroll list makes one of
each.

- **`UiSlice`** draws the sprite as a 9-slice: corners keep their size,
  edges stretch — panels and buttons from one skin sheet.
- **`UiStack`** lays its children out in a row or a column, in `slot`
  order, with spacing and padding.
- **`UiScroll`** scrolls and clips its children; the wheel scrolls it and
  the focus moving into it brings the focused control into view.

## Controls

`UiButton`, `UiToggle` (on a button), `UiSlider` and `UiTextField` share
one focus, moved by the mouse, the arrow keys, a pad's D-pad and touch.
Read them in a tick:

```rust
if tick.ui.clicked(play_button) { /* start */ }
if tick.ui.changed(volume) {
    let value = tick.world.get::<UiSlider>(volume).map(|s| s.value);
}
if tick.ui.submitted(name_field) { /* … */ }
```

Text fields take typing and IME composition. A button's faces can be
frames of an atlas (`UiButton::frames`).

## Text, wrapped and translated

`Text::max_width` wraps lines between words (in a `UiRect`, at the rect's
width). `Text::key` names a string in `assets/locale/<language>.ron` —
`(version: 1, strings: {"menu.play": "Jugar"})` — and the text shows the
current language's string; `tick.locale.set_language("es")` switches it at
once. A missing string shows its key.

## Touch

On a touch screen the first finger is the pointer, so a tap is a click.
Bindings like `Touch(BottomLeft, Right)` in the input map make a floating
virtual stick; `Touch(BottomRight, Hold)` an on-screen button. The default
input map binds walking and jumping that way.
